# GAB MOTO Estética — primeira versão

Site estático responsivo feito com HTML, CSS e JavaScript puro.

## Arquivos
- `index.html`: conteúdo e estrutura.
- `style.css`: identidade visual e responsividade.
- `script.js`: menu mobile, ano automático e link de contato.

## Antes de publicar
1. Abra `script.js`.
2. Troque `CONFIGURAR_NUMERO_AQUI` pelo WhatsApp comercial no formato internacional, apenas números. Exemplo fictício: `5511999999999`.
3. Substitua os blocos escuros identificados como espaços de foto por fotografias reais da GAB MOTO.
4. Revise textos, serviços, cidade e links.

## Fotografias
Os blocos escuros são espaços reservados e não representam trabalhos realizados. Use fotografias próprias, com autorização de quem aparece nelas, e otimize os arquivos para web.

## Publicação
Pode ser publicado como site estático em um serviço de hospedagem compatível, como Netlify ou GitHub Pages. Não contém banco de dados nem funções de cadastro nesta versão.
